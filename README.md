# Random Task

A browser extension that gives you a fresh, hands-on task or mini project for your field. Pick an area of interest (developer, electronics, chemistry, or anything you type), press a button, and get a task with a short description, steps and a time estimate.

With an API key, every task is generated by AI and is different each time. Without one, the extension falls back to a built-in list.

## Features

- Full-screen page opened from the extension icon
- Field chips plus a free-text field for anything else (Biology, Music, Mechanical...)
- Effort filter: 1 hour, a weekend, or a week
- AI-generated tasks with title, description, steps and time estimate
- Remembers recent tasks so it avoids repeating them
- Offline fallback list in `tasks.json`
- Save tasks you like (stored locally in the browser)

## Install (development)

1. Clone the repo:
   ```bash
   git clone https://github.com/<your-username>/random-task.git
   ```
2. Open `chrome://extensions` (or `edge://extensions`).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the project folder.
5. Click the extension icon. The app opens in a new tab.

## Enable AI generation

1. In the app, click **AI settings**.
2. Paste your Anthropic API key and save.

The key is stored only in your browser (`chrome.storage.local`). It is never written to the code or sent anywhere except `api.anthropic.com`.

> **Do not hardcode an API key in the source code or commit one to Git.**
> For a public release, route requests through your own backend (for example a Cloudflare Worker) so the key stays on the server. See the roadmap below.

## Adding built-in tasks

Edit `tasks.json`. Each category is an array of tasks:

```json
{
  "Developer": [
    { "title": "Build a CLI to-do app", "description": "Ship add, list and done commands.", "time": "A weekend" }
  ]
}
```

New categories appear automatically as chips.

## Privacy

No analytics and no tracking. Settings, saved tasks and your API key stay in local browser storage. When AI is enabled, only the chosen field and effort level are sent to the API.
